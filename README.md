## 🧑‍💻 Sobre mí (TL;DR)

- 🛠️ Administro sistemas **Linux y Windows**: si tiene una terminal, sé hablar con ella (y si tiene GUI, también, a regañadientes).
- 🌐 Desarrollo **full-stack** con **TypeScript/Node.js, React y Python**, sobre todo herramientas internas que resuelven problemas reales y no slides de PowerPoint.
- 🐳 Automatizo todo lo que se mueve con **Docker y scripting**. Mi regla es simple: lo que hago dos veces, la tercera lo hace un script.
- 🏠 En mi tiempo libre cacharreo con **self-hosting, hardware y entornos locales**. Mi homelab tiene más servicios que algunas empresas.

- 🤖 **Agentes de IA + tooling local**: flujos de trabajo con LLMs que de verdad ahorran tiempo, corriendo en local siempre que se pueda.
